Context
What this adds and why

The existing Highlight Box (callout) style is designed for short, single-idea content — a tip, a warning, a reminder. It works well at one to three lines. The AI literacy modules introduced a need for a callout that can hold substantially more content: action steps with bulleted instructions, scenario prompts, strategy explanations, and synthesis moments. The existing callout doesn't scale to this gracefully.

The Content Card Callout fills that gap. It is additive — it does not replace the existing Highlight Box. The two styles serve different purposes and can appear on the same page.

Relationship to existing styles
The existing Highlight Box remains unchanged. The Content Card Callout is a new style entry in the platform style system, with its own prod note notation. It inherits the AI literacy color palette and shares the left-accent border language of the existing system but introduces a mandatory title field and support for richer body content.

Icon alignment rule
Icons are always top-aligned in Content Card Callouts. Middle alignment is only appropriate for single-line callouts (existing Highlight Box at short lengths). For multi-line content, middle alignment floats the icon in whitespace and breaks the visual relationship with the title.
Icon variants — navy, full border, 660px
No Icon — Title Only

Title sits flush with the left edge of the content area. Clean and direct. Best for activity containers and action steps where the content itself is the focus.

⚡ Standard Icon — Top Aligned

Icon (20px) sits at the top, aligned to the title's cap-height. Body text indents to align with the start of the title text. Works for 2–6 lines of body content without awkward floating.

📋 Small Icon — Top Aligned, No Body Indent

Small icon (16px) anchored to title. Body text does not indent — the small icon is decorative and does not create a column break. Use when the icon adds context without structuring the layout.

Make It Real

Now it's time to apply what you've learned.

Your action step:

Find a job posting you're interested in (or one you've recently applied to). Identify the three audiences who will read your cover letter for that position. Then answer these questions:

  • What qualifications will the recruiter prioritize?

Write down your answers. You'll use them as a foundation when you start drafting your cover letter in the next microlesson.

Left border only, no border radius, light background — "Example" label and optional pill tag on the same line, body text below. Uses the existing Highlight Box structure with the new pill pattern.
Any color Left border only No corners
