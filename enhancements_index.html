About this list
These enhancements were identified during the development of ML 2.6 (Your Verification Toolkit) and represent platform capability gaps that constrain instructional design across all AI literacy microlessons. They are listed in priority order — highest instructional impact and broadest recurrence across modules first. Each item links to its full requirements document where available.

High Priority
E1
Tabbed Scenario Switcher
Audience-lens navigation for the layered example pattern. Three side-by-side tabs (Student · Job Seeker · Everyday Life) that switch content panels in place — recurs across every microlesson in Modules 2–4.
High priority Doc ready Phase 1 MVP
→
E2
Self-Assessment Question Type
A non-graded question type where all answers are valid and each choice triggers unique, personalized feedback. No score, no right/wrong indicator. Essential for reflection moments in professional skills and AI literacy content.
High priority Doc ready Phase 1 MVP
→
E3
Questions Inside Show/Hide Sections
Scenario-linked embedded assessment — knowledge check questions placed inside expandable sections, directly connected to the stimulus content the learner just read. Currently questions must be decoupled from their scenarios, weakening instructional connection.
High priority Pending Phase 1 MVP
—
E4
Progressive Question Unlock
Sequential step-by-step interactivity — questions unlock one at a time as the learner answers each preceding question. Enforces the SIFT method as a sequential process rather than a checklist. Answering (correctly or not) unlocks the next step.
High priority Pending Phase 1 MVP
—
Medium Priority
E5
Scenario-Linked Question Sets
Conditional questions based on which scenario the learner opened. When a learner engages with the Job Seeker scenario, they see job-seeker-specific questions — not generic questions written to work regardless of context. Requires E1 and E3 as prerequisites.
Medium priority Pending Phase 2
—
E6
Completion State / Content Reveal
Post-practice synthesis triggered by question completion — a verdict card, summary, or Real Talk callout that appears after the learner has answered all questions on a page. Currently all post-practice content must be always-visible, reducing its impact.
Medium priority Pending Phase 2
—
E7
Hotspot on Formatted Text
Clickable claims directly within AI output cards — learners click on specific flagged statistics, named organizations, or attributed quotes to see SIFT verification prompts. Currently hotspot questions require a static image base; styled HTML text cannot be used as a hotspot target without export to image.
Medium priority Pending Phase 2
